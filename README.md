# Mr Descargaelputotema

**Interfaz gráfica para descargar audio de YouTube y Spotify de forma fácil y rápida.**

![Logo](icono.png)

## ✨ Características

- Descarga audio de YouTube en formato MP3 (320 kbps) o video MP4.
- Descarga canciones, álbumes y playlists de Spotify.
- Soporta la descarga de playlists completas de YouTube.
- Interfaz simple con pestañas y feedback visual.
- Totalmente portable, no requiere instalación.

## 🚀 Uso

1. Descarga la última versión desde la pestaña [Releases](https://github.com/aimo247/Mr-Descargaelputotema/releases).
2. Descomprime el archivo .zip en cualquier carpeta.
3. Ejecuta `Mr Descargaelputotema.exe`.
4. Sigue las instrucciones en pantalla para descargar tu música.

## 🛠️ Tecnologías

- [Python](https://www.python.org/) con [pywebview](https://pywebview.flowrl.com/).
- [yt-dlp](https://github.com/yt-dlp/yt-dlp) para descargas de YouTube.
- [spotdl](https://github.com/spotDL/spotify-downloader) para descargas de Spotify.
- [FFmpeg](https://ffmpeg.org/) para la conversión de audio.
